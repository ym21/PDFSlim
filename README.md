# PDFSlim

PDFSlim は、スキャンPDFや画像中心PDFをローカルだけで軽量化する Windows 10/11 向け Python/PySide6 アプリです。PDFや画像を外部サービスへ送信せず、元PDFを上書きしません。

## セットアップ

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
pdfslim
```

ファイル選択、フォルダ追加、またはPDFのドラッグ&ドロップで複数ファイルをキューに追加できます。プリセットを選択したあと、解像度、JPEG品質、カラーモード、詳細チェックボックスを個別に変更できます。出力は既定で `Compressed` フォルダへ `*_compressed.pdf` として保存され、同名ファイルがある場合は連番になります。

### 詳細設定

- **解像度（DPI）**: ページや画像を何ドットで表現するかの上限です。150-200 DPIは画面閲覧向け、250-300 DPIは印刷向けです。「元解像度を維持」では縮小しません。
- **JPEG品質**: 1-100で写真の再圧縮品質を指定します。値を下げるほど小さくなりますが、輪郭や文字の周囲にノイズが出やすくなります。
- **カラーモード**: カラー維持／グレースケール／白黒2値から1つだけ選びます。グレースケールと白黒2値はページ全体を画像化するため、文字検索やリンク等は失われます。
- **ダウンサンプリング**: 指定DPIを超える画像だけ縮小します。容量は減りますが細部の解像感が下がります。
- **JPEG再圧縮**: 写真向けの非可逆圧縮です。品質を下げるほど小さくなりますが、文字・細線にノイズが出ます。CMYKなど複雑な画像は、表示時の色変換を使って安全にRGB化してから差し替えるため、ネガ状の反転を防ぎつつ文字・リンク・ベクター構造を維持します。
- **自動余白除去**: 画像内の白に近い均一な外周をトリミングし、元の配置枠へ合わせ直します。内容によっては拡大や縦横比の変化が生じるため、結果を確認して使用してください。
- **文書情報（作者・作成ソフト・日時）を削除**: 共有時のプライバシー保護が目的です。容量削減効果は通常ごくわずかです。

保存時にはPDFのストリームとオブジェクト構造を自動的に整理します。この処理は常に安全に行われるため、個別の「PDF内部最適化」設定はありません。

## DPIと画像置換

画像を配置するページ内容の `cm` / `Do` 行列を読める場合は、実際の表示サイズから実効DPIを算出します。特殊なPDFで配置を読めない場合は、画像がページ全体を埋めるという安全な近似を使います。ページサイズも取得できない場合は縮小しません。いずれの場合も、目標DPIを下回る画像をアップスケールすることはありません。

JPEG再圧縮をOFFにした場合、他の変換が不要なら元画像ストリームを保持します。グレースケール／白黒2値を選ぶと、全オブジェクトをページ画像として再描画し、ページ構造そのものを軽量化します。この場合、文字の選択・検索、ベクター、リンク、フォームは失われます。白黒2値は局所的な背景明度を基準に判定するため、暗い写真や色付き背景が一面真っ黒になる現象を抑えます。保存データは常に1-bit相当の可逆PNGです。

## エラーとキャンセル

壊れたPDF、パスワード付きPDF、権限エラーはファイルごとに失敗として表示し、バッチの残りは継続します。一部画像の変換失敗は警告として結果に残します。出力は保存先の一時ファイルへ完成させてからリネームするため、キャンセルや保存失敗で部分PDFを残しません。

## テスト

```powershell
python -m pytest
```

`tests/test_core.py` には Pillow で生成した画像を pikepdf で配置する統合テストが含まれます。pikepdf がない環境では該当テストを自動的にスキップします。

## Windowsバイナリの作成

```powershell
python -m pip install -e ".[dev,build]"
.\scripts\build_release.ps1 -Version 0.1.0
```

`dist` にWindows x64用の単体実行ファイル、配布ZIP、SHA-256チェックサムを生成します。
