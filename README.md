# PDFSlim

PDFSlim は、スキャンPDFや画像中心PDFをローカルだけで軽量化する Windows 10/11 向け Python/PySide6 アプリです。PDFや画像を外部サービスへ送信せず、元PDFを上書きしません。

## セットアップ

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
pdfslim
```

ファイル選択、フォルダ追加、またはPDFのドラッグ&ドロップで複数ファイルをキューに追加できます。プリセットを選択したあと、解像度、JPEG品質、カラーモード、詳細チェックボックスを個別に変更できます。出力は既定で `Compressed` フォルダへ `*_compressed.pdf` として保存され、同名ファイルがある場合は連番になります。

## DPIと画像置換

画像を配置するページ内容の `cm` / `Do` 行列を読める場合は、実際の表示サイズから実効DPIを算出します。特殊なPDFで配置を読めない場合は、画像がページ全体を埋めるという安全な近似を使います。ページサイズも取得できない場合は縮小しません。いずれの場合も、目標DPIを下回る画像をアップスケールすることはありません。

JPEG再圧縮をOFFにした場合、他の変換が不要なら元画像ストリームを保持します。ダウンサンプリングや色変換だけが必要な場合は、JPEG化を強制せず、8-bitのFlate画像ストリームとして再配置します。

## エラーとキャンセル

壊れたPDF、パスワード付きPDF、権限エラーはファイルごとに失敗として表示し、バッチの残りは継続します。一部画像の変換失敗は警告として結果に残します。出力は保存先の一時ファイルへ完成させてからリネームするため、キャンセルや保存失敗で部分PDFを残しません。

## テスト

```powershell
python -m pytest
```

`tests/test_core.py` には Pillow で生成した画像を pikepdf で配置する統合テストが含まれます。pikepdf がない環境では該当テストを自動的にスキップします。
